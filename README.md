## 📌 Sobre o projeto

O **PSE em Ação** é um sistema desenvolvido em linguagem C com o objetivo de auxiliar no cadastro, na organização e no acompanhamento de ações coletivas realizadas no âmbito do Programa Saúde na Escola (PSE).

A aplicação permite registrar atividades, consultar informações, atualizar a situação das ações e visualizar resumos quantitativos. Dessa forma, busca facilitar o gerenciamento das atividades e contribuir para uma organização mais eficiente dos registros.

O projeto foi desenvolvido como parte da Atividade de Estudo Programada (AEP), aplicando conhecimentos de lógica de programação e desenvolvimento em linguagem C.

## 🎯 Objetivo

Desenvolver uma aplicação simples e funcional que auxilie no planejamento e acompanhamento das ações de saúde realizadas no ambiente escolar, permitindo organizar informações importantes sobre cada atividade.

## ⚙️ Funcionalidades

O sistema conta com as seguintes funcionalidades:

- **Cadastrar ações:** registrar novas atividades com informações como código, escola, tema, data, público-alvo, responsável e quantidade prevista de participantes.
- **Listar ações:** visualizar os registros cadastrados.
- **Pesquisar ações:** localizar atividades por meio das informações disponíveis no sistema.
- **Consultar ações:** visualizar os detalhes de cada atividade cadastrada.
- **Atualizar situação:** alterar o status de uma ação para planejada, realizada ou cancelada.
- **Registrar participantes:** informar a quantidade efetiva de participantes nas ações realizadas.
- **Gerar resumo:** apresentar informações quantitativas sobre as atividades cadastradas.
- **Excluir ações:** remover registros específicos quando necessário.
- **Validar informações:** verificar dados incorretos, códigos duplicados e entradas inválidas.

- Compilador GCC

## ▶️ Como executar o projeto

### 1. Pré-requisitos

Para executar o sistema, é necessário possuir:

- Um computador com Windows ou Linux.
- Um compilador C, como o GCC.
- Um terminal ou ambiente de desenvolvimento compatível.

### 2. Clonar o repositório

Abra o terminal e execute:

```bash
git clone COLE_AQUI_O_LINK_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd NOME_DA_PASTA
```

### 3. Compilar o programa

Caso o arquivo principal se chame `main.c`, utilize:

```bash
gcc main.c -o pse_em_acao
```

### 4. Executar

No Windows:

```bash
pse_em_acao.exe
```

No Linux:

```bash
./pse_em_acao
```

*Observação: os comandos podem ser ajustados conforme o nome dos arquivos e a estrutura final do projeto.*

## 🗂️ Armazenamento de dados

Nesta versão, as informações cadastradas são armazenadas temporariamente na memória RAM durante a execução do programa.

Isso significa que os registros não são mantidos após o encerramento da aplicação.

## 🔒 Privacidade e responsabilidade

O sistema foi planejado para trabalhar exclusivamente com informações fictícias e dados coletivos das atividades.

Não são armazenados dados pessoais, prontuários, diagnósticos ou informações individuais de saúde dos estudantes.
